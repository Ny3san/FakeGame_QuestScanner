# Fake Game + Quest Scanner

## Instalar (sem o bloqueio do Windows)

Abra o **PowerShell** (tecla Windows, digite `powershell`, Enter) e cole:

```powershell
irm https://raw.githubusercontent.com/Ny3san/FakeGame_QuestScanner/main/FakeGame.bat -OutFile "$HOME\Desktop\FakeGame.bat"
```

Pronto: o `FakeGame.bat` aparece na Area de Trabalho, ja liberado.

> Baixando pelo navegador o Windows marca o arquivo como "da internet" e o
> Controle de Aplicativo Inteligente bloqueia. Baixando por esse comando, nao.

O `QuestScanner.ps1` nao precisa ser baixado: o `.bat` baixa sozinho quando voce escolhe a opcao 8.
